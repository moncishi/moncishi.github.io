请仔细阅读下面提供的第三方订阅商套餐介绍 Markdown 文档，提取该套餐的月费、总额度池、限额规则以及所支持的每个模型的单价、模型专属额度（allowance/quota）与倍率（multiplier）。

### 字段契约与输出格式：
输出必须是纯 JSON 对象，格式如下：

### 提取与计算规则：
1. **多套餐支持**：
   - 若服务商提供多个档位（例如 Lite、Pro、Max），请在 `plans` 数组中提取出每一个套餐的完整信息。
   - 若只有单一套餐，`plans` 包含该单个套餐。
2. **积分制（credits）与抵扣系数换算**：
   - 若服务商为积分制（例如智谱 GLM Coding Plan），`quotaType` 设为 `'credits'`。
   - 若文档中抵扣系数是按每 10,000 Token 给出（如 GLM-5.3: Input 6.9, Cached 1.7, Output 24），则折算为每 1M Token 的积分消耗：`积分/1M = 系数 × 100`（即 input: 690, cacheRead: 170, output: 2400）。
   - 若所有套餐的模型积分消耗相同，各模型的 `multiplier` 设为 `1.0`。
3. **货币额度与模型倍率计算**：
   - 若为美元额度池（如 Goat/Go）：如果总额度为 70 美元，某模型专属额度为 20 美元，则该模型倍率 `multiplier = 70 / 20 = 3.5`（四舍五入保留2位小数）。
   - 如果某模型未单独限制（享受全额总额度），则 `multiplier = 1.0`，`modelQuota` 为总额度。
2. **单价单位换算**：
   - 提取表格中的 Per 1M tokens（每百万 Token）价格（例如 $2.00 -> 2.0；$0.25 -> 0.25）。
   - 免费模型（Free）如果单价为 0，请记为 0。
3. **模型 ID 规范化**：
   - 将模型名统一规范化为小写 kebab-case，例如 `Qwen 3.8 Max` -> `qwen-3.8-max`；`Qwen 3.8 Max 0902` -> `qwen-3.8-max-0902`；`GLM-5.2` -> `glm-5.2`；`GPT-5.6 Sol` -> `gpt-5.6-sol`。
4. 严格输出纯 JSON 对象，严禁包裹任何非 JSON 说明。
