# 0003. 扩展文本、图片、视频多模态与标准分辨率阶梯定价架构

大模型生态已由纯文本 LLM 扩展至图像生成与视频生成多模态。文本按 Token 计费，图片按张计费，视频按秒计费，且视觉模型普遍具有多分辨率定价差异。我们决定在模型体系中引入 `modality: 'text' | 'image' | 'video'`，并为图像（1k、2k）和视频（480p、720p、1k、2k）建立标准化的离散分辨率阶梯单价字段。这消除了非结构化图文视频模型的定价混乱，使得全模态模型均能在统一的横向比价引擎中进行标准化衡量。

## Status

Accepted

## Considered Options

- **仅支持文本模态（旧方案）**：仅有 input/output/cacheRead 字段，完全无法接入 Midjourney、FLUX、CogVideoX 等流行生图/生视频模型。
- **动态自由键值对定价**：允许任意字符串作为计量单位（如 "per_call", "per_minute"）。缺点是无法进行自动化的单位换算、排序与多方案横向对比。
- **标准模态与规范化分辨率阶梯（选中）**：明确界定三种模态，图像统一 1k/2k 档，视频统一 480p/720p/1k/2k 档。

## Consequences

- 模型与 Provider 的计费结构由单一 Token 维度进化为联合类型（Discriminated Union）。
- 排序引擎需根据当前选中的模态自适应切换核心指标：文本以 `每百万 Token 成本` 排序，图像以 `综合单张成本`（默认 1k 档）排序，视频以 `综合每秒成本`（默认 720p 档）排序。
